- 每个区间使用 10001 个含端点采样，再使用 10001 个半步错开采样。
- 两套网格合计 2420122 个不同的参考姿态。
- 相邻端点使用 MuJoCo 的关节位置差分和积分函数连接。
- 检查全部原生手部视觉网格到 z=0.72 m 桌面的距离。
- 没有推进物理、施加控制器或修改参考。
