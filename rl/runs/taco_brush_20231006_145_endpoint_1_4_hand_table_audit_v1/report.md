# endpoint 1–4 手—桌关系专项对比

## 现象概述

参考手和实际手在 endpoint 0→4 内都还没有穿桌，但实际手从第一个控制周期开始逐渐落后于参考手。
这段误差几乎全部表现为左右手腕一起向下滞后；到 endpoint 4，实际手比参考手少了约 4 mm 的离桌空间。
随后在 endpoint 4→5 内记录到参考仍在桌面上方、实际手进入桌面的现象。

## 数据可信度

- 本次短回放共 `67` 个物理子步，全部在线字段与完整插值回放的同长度前缀逐字段一致：`True`。
- 在线原生距离与保存姿态离线重算的最大差为 `0.000e+00 m`。
- 下表和全部渲染都从保存的步后 `qpos` 重新执行前向计算，姿态、原生几何和 `state_time_s` 对应同一时刻。
- 执行器力和代理接触属于紧邻该步后状态之前的 2 ms 物理区间，日志另存了区间起点与终点，没有把它们标成终点瞬时量。
- 渲染只隐藏刷子和碗，便于观察手与桌面；没有修改物理运行。

## 最早偏离

- 第一次出现实际离桌量小于参考：步后 `6 ms`，0→1 的第 `3/17` 个子步，差 `-0.009 mm`。
- 差值第一次超过 0.05 mm：步后 `8 ms`，0→1 的第 `4/17` 个子步，差 `-0.050 mm`。
- 这 67 个子步中的手—桌代理接触数：`0`；因此 endpoint 0→4 的向下偏离发生在桌面接触之前。

## 为什么主要是竖直跟踪滞后

- endpoint 4 左/右手腕竖直位置误差分别为 `-4.132` / `-4.133 mm`。
- 同一时刻左/右手的离桌空间差分别为 `-4.230` / `-4.189 mm`。
- 离桌空间差与手腕竖直误差的相关系数为左手 `0.999987`、右手 `0.999996`。两条曲线几乎重合。
- 两个竖直执行器的位置增益均为 `1000.0 N/m`，速度反馈系数约 `98.433 N·s/m`，且没有执行器力上限；现有数据不支持“达到力饱和”这一解释。
- 初始实际速度被设为零，而参考手在前四段持续向下运动。位置控制器逐步追赶移动目标，形成约 4 mm 的稳定滞后；这是当前数据最直接支持的解释。
