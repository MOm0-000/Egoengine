# 20231006_145 低层目标保持与子步插值对照

## 观测结果

把整周期保持改为逐物理子步插值后，记录到的早期穿桌深度发生变化，但穿桌仍然存在。

在关键区间 `4->5`，参考路径全程安全，最小余量为 `2.433538 mm`。原方案在 endpoint 5 的左手穿透为 `-2.447222 mm`；插值方案为 `-1.370980 mm`。穿透深度减少 `1.076241 mm`，约 `44.0%`，但仍明显超过 `0.05 mm` 容差。

插值方案第一次超过容差发生在区间 `4->5` 的第 `11` 个物理子步，步后状态时刻 `0.156000 s`。当时参考仍高于桌面 `3.825626 mm`，真实手部已经进入桌面 `0.122376 mm`。

## 固定条件

- 两次运行使用相同场景、机器人参考、桌面、自然落座物体状态、物理时间步、控制周期、执行器增益、碰撞参数和停止条件。
- 唯一改变是控制周期内的位置目标时序。
- 原方案在每个周期开始时直接使用下一个端点目标，并保持 16 或 17 个物理子步。
- 插值方案从当前端点目标出发，每个物理子步前进 `1/N`，最后一个子步到达下一个端点。
- 没有修改参考轨迹，没有增加辅助力，没有运行强化学习或参数搜索。

## 是否出现“参考和 Replay 都不穿桌”

没有。原方案共有 `25` 个已审计的“参考安全、Replay 穿桌”手侧观测。插值后：

- 变为安全：`0` 个；
- 仍然穿桌：`25` 个；
- 新增穿桌：`0` 个。

在插值 Replay 的全部 2017 个物理子步中，有 `704` 个子步属于“参考安全但真实状态穿桌”。真实手部全程最深进入桌面 `3.495160 mm`。参考插值路径本身在后半段也会进入桌面，子步采样最深 `0.978099 mm`。
