# 20231006_145 全参考路径密集手-桌检查

## 结论

如果“完全安全”指手部原始网格在任何时刻都不能低于桌面，答案是：**否**。

全路径最小距离为 `-0.978808 mm`，位于区间 `107->108` 的 `alpha=0.5129`，对应参考时刻 `3.583763333 s`。负号表示手部网格低于桌面。最深位置是 `left_hand_pinky_link2` 的 `left_pinky_link2_visual`，顶点 `333`。

这个区间的两个端点本身都在桌面上方：endpoint 107 的最小距离为 `0.000005790 mm`，endpoint 108 为 `0.000001118 mm`。但插值到区间中部时，左手小指第二节沿弧线向下扫入桌面。

若沿用当前审计允许的 `0.05 mm` 数值容差，则整条路径是否通过：**否**。这两个结论不矛盾：前者要求严格不穿透，后者允许小于 `0.05 mm` 的数值误差。

## 检查范围和方法

- 仅检查最新正式参考 `20231006_145`，共 `122` 个端点、`121` 个相邻区间，时间范围 `0.000000000` 到 `4.033333333 s`。
- 每个区间均匀检查 `10001` 个位置，相邻位置的 `alpha` 间隔为 `0.0001`；去除区间共享端点后共有 `1210001` 个不同位置。
- 每个区间使用 MuJoCo 的关节位置差分与积分函数连接两个参考端点。机器人关节为 `6` 个直线关节和 `30` 个转动关节。
- 距离取手部原始可视网格到 `z=0.72 m` 桌面的最小有符号距离。负数表示穿入桌面。
- 只做位置计算，没有推进物理，没有施加控制器，也没有改变参考、桌面或容差。

## 能说明什么

这条完整参考插值路径不但没有处处保持正距离，而且在多个区间明显超过现有容差。因此，只检查 MINK 离散端点不足以证明连续参考路径可执行。该检查只回答手和桌面的几何关系，不评价手和物体、自碰撞或真实动力学跟踪。
