# Brush 测量代码修复与同一平面重核 v1

**结论：测量/报告代码已修复；真实几何误差原因仍未确定，约两厘米差异没有被证明解决。**

## 六项修复

- **A 同一平面：** 修正前后跟踪同一张完整平面，不再修正点云后另找近水平平面。
- **B 归一化：** normal 和 offset 同除以法向量长度，不再移动平面。旧 Brush 实验是否触发此缺陷仍无证据。
- **C 验证不截断：** 背景验证点不再按候选平面 ±10 mm 截断；独立桌面验证和绝对位置精度均未完成。
- **D 强制排除：** 左右手名义投影不问深度前后均禁用；独立手/不确定区域 mask 不存在，轮廓外污染仍未知。
- **E 候选与准入：** 有限候选保留完整矩阵和求解状态；未收敛、向量范数越界、证据不足不再混成一个“数值失败”。
- **F 完整汇总：** 刷子、碗、左右手分别统计；改善与恶化并存时明确报混合结果，`0.0` 不再当成缺失。

## Frame 139 回归

Open3D WORLD_FIXED 同一原平面变换后 tilt=`28.6271405689°`，offset=`0.5297505385 m`；旧报告另行重拟合得到 tilt=`6.7788303309°`，offset=`0.6802256081 m`。该候选的平移和旋转均超出原准入范围，因此只是诊断回归；旧数字不能再代表同一桌面。

## 旧报告换平面的影响

Open3D WORLD_FIXED 的碗距离在 `131` 帧同时有旧值与同平面新值；旧重拟合值减新值的最大绝对差为 `231.817 mm`。该值只表明旧报告换平面可大幅改变结果，不证明原平面是现实真值。

## 必须降级的旧结论

- 筛选后的约 ±8 mm 只是候选平面附近残差，不能证明绝对桌面精度。
- 旧严重穿透数字混入了重新选平面的影响，必须以逐帧同平面重核表解释。
- 碗底/刷子底距离可报告，但不能单独归因相机标定错误。
- 历史 `hand` 是真人手模型，不是 MINK v2 机器人手。

本轮没有读取 Depth 视频，没有重新求解校准、重拟合桌面或运行 MINK/physics/Replay/MPC/RL。
