# Pour MANO-XHand Morphology Audit

This is a read-only diagnostic for the preserved Pour episode. It uses MANO
v1.2 zero betas and identity pose for the human neutral shape, and XHand MJCF
`qpos0` for the robot. Both are localized to a wrist-centered anatomical frame
with palm-normal `+X`, wrist-to-middle-MCP `+Z`, and `+Y = cross(+Z,+X)`.

The audit is in
[`runs/taco_pour_morphology_audit_v3/report.json`](/data_all/zzx/3.2RL/runs/taco_pour_morphology_audit_v3/report.json)
and is generated by
[`scripts/audit_taco_morphology.py`](/data_all/zzx/3.2RL/scripts/audit_taco_morphology.py).

## Measurements

The human neutral palm width and length are `66.918 mm` and `94.731 mm`; the
XHand values are `63.699 mm` and `108.469 mm`. Thus the palm width ratio is
`0.952` and palm length ratio is `1.145` for both hands.

The XHand/MANO total chain-length ratios are:

| finger | right | left |
| --- | ---: | ---: |
| thumb | 1.267 | 1.267 |
| index | 1.150 | 1.150 |
| middle | 1.087 | 1.096 |
| ring | 1.156 | 1.156 |
| pinky | 1.359 | 1.359 |

The global chain ratio is about `1.186`, but the per-finger spread is about
`0.272`. A single global scale therefore cannot represent the hand. The XHand
has fewer articulated intermediate bodies for middle/ring/pinky, so their
segment-by-segment ratios are deliberately reported as not comparable rather
than inventing a correspondence.

Across all 198 Pour rows, p95-p05 ratio variation is below `0.05` for every
finger. It is smallest for index/middle/ring and largest for thumb/pinky,
especially in the grasp-like rows. This supports a bounded engineering
candidate, not an exact fixed calibration.

## Diagnostic target scaling

Two isolated probes scale only each fingertip's wrist-relative position:

* `global_chain`: one per-hand scale fitted to all five chain lengths;
* `per_finger_chain`: one scale per finger.

Wrist targets, orientation targets, object poses, collision pairs, and source
references are untouched. With the same six representative rows and inherited
MINK settings, the per-finger candidate reduces full-pose fingertip position
mean from `11.52 mm` to `7.52 mm`, and wrist-position mean from `34.48 mm` to
`18.36 mm`. This is evidence that morphology contributes to the residual, but
the candidate also changes where the human fingertip is requested relative to
the objects. It has not been visually or cross-task validated and must not be
used in Replay or RL.

## Decision

The morphology problem is characterized but not solved. The geometric contract
remains unresolved and the weight grid remains blocked. The next admissible
step is to repeat the same neutral-morphology audit on the Bowl and Plate
episodes, then use the exact triptych renderer for a coarse visual check. Only
a mapping that preserves contact/task geometry and improves all three tasks may
be promoted to a formal retargeting candidate.
